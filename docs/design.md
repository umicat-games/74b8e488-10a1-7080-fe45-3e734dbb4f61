# 河流漂流记 — Game Design Document

## 概念

玩家驾驶一艘像素风格的小船，在从下往上流动的河流中航行。屏幕左右两侧是草地、森林、雪山等不同场景风光，河中布满石头和鱼类。玩家需要躲避危险、收集小鱼作为食物，最终驾船抵达每关终点码头。

* * *

## 画面布局（1280×720 横屏）

```
┌────────┬────────────────┬────────┐
│        │                │        │
│ 左岸风景 │    河    流     │ 右岸风景 │
│  320px │    640px       │  320px │
│ (1/4)  │    (1/2)       │  (1/4) │
│        │  水流↑ 障碍↑   │        │
│        │  小鱼↑ 石头    │        │
└────────┴────────────────┴────────┘
```

-   **河流**：中央640px，水面向上滚动，障碍物和鱼从上方出现
    
-   **两侧风景**：各320px，做**视差滚动**（远景慢、近景快），随关卡主题变化
    
-   **河岸边界**：两侧有软边界，船靠近河岸会给出视觉警告，不可驶出河道
    

* * *

## 核心循环

1.  河流自动向上滚动，小船随水流前进
    
2.  玩家用方向键在河道内操控小船位置
    
3.  撞到**小鱼** → 收入底部背包格（最多8格）
    
4.  按**数字键**吃背包里的鱼 → 回血
    
5.  被**大鱼**撞到 → 失血
    
6.  撞到**石头** → 失血 + 船体受损特效
    
7.  **空格跳跃** → 短暂腾空，躲避水面障碍，落水溅起像素水花（约1秒冷却）
    
8.  抵达终点**码头** → 过关，进入下一个场景关卡
    

* * *

## 控制方案

按键操作← →在河道内左右移动↑加速前进（逆流而上更快）↓减速 / 稍微后退空格跳跃腾空（冷却约1秒，不可连跳）1 – 8吃背包对应格子的鱼（恢复血量）

## 障碍与实体

### 小鱼（可收集）

-   在河面随机游动，体型小
    
-   碰触即收入背包（若背包满则无法收集，给出提示）
    
-   种类多样，不同的鱼回复不同血量
    

### 大鱼（危险）

-   体型明显大于小鱼，颜色/轮廓有别
    
-   碰触扣血（约20%最大血量）
    
-   部分大鱼会主动追踪小船
    

### 石头（固定障碍）

-   固定在河中，不移动
    
-   碰触扣血（约15%最大血量）+ 船体晃动特效
    
-   形状不规则，像素风格
    

* * *

## 血量与生命系统

-   满血 = 100 HP
    
-   归零即游戏结束（显示本关得分、收集鱼数）
    
-   关卡结束时，HP **不恢复**（保留到下一关，增加压力）
    
-   HUD顶部显示HP血条
    

* * *

## 背包系统（底部工具栏）

-   屏幕底部常驻8格工具栏，Minecraft格子风格
    
-   收集的鱼放入格子，显示图标 + 数量
    
-   按对应数字键消耗一条鱼（-1数量），回复一定HP
    
-   格子满时无法再收集新鱼，需先消耗
    

* * *

## 关卡结构（场景主题）

每关两侧风景做**多层视差**：最远层（山/天空）滚速最慢，近层（树/草）稍快，营造纵深感。

| 关卡 | 场景 | 两侧风景 | 滚速 | 特点 |
|------|------|----------|------|------|
| 1 | 草地平原 | 绿草地 + 低矮灌木 | 慢 | 障碍少，鱼多，入门关 |
| 2 | 秋色森林 | 橙黄落叶树林 | 中 | 石头增多，落叶视差特效 |
| 3 | 雪山冰川 | 白雪山峰 + 松树 | 快 | 冰块代替石头，水面偏蓝白 |
| 4+ | 循环递增 | 混合场景 | 更快 | 障碍密度提升，大鱼更凶 |

## 关卡生成方式（混合制）

采用**程序生成 + 关卡参数控制**：障碍整体随机出现，但难度曲线由预设参数控制，并穿插设计好的「小模式」，让每关有节奏感且每次体验略有不同。

### 每关参数（可调）

每关在 `rules.json` 中定义一组参数：

- **滚动速度**：河流向上滚动的速度
- **石头密度**：每隔多少距离生成一块石头
- **小鱼生成率**：小鱼出现的频率
- **大鱼生成率**：大鱼出现的频率（及是否会主动追踪）
- **关卡总长度**：每关河段的距离（单位：像素）

### 预设「小模式」（局部手工设计）

程序生成中会随机穿插以下障碍组合，增加节奏变化：

- **石头三角**：3块石头呈三角形排列，中间留出通道
- **双鱼夹击**：两条大鱼从左右方向靠近
- **鱼群过境**：一群小鱼密集游过，撞到全部收入（或背包满爆出提示）
- **石头走廊**：多块石头排成两列，玩家需穿越窄道

### 关卡结束节奏

每关分三段：
1. **前 60%**：正常难度，障碍随机生成
2. **中间 20%**（高潮）：集中出现「小模式」，紧张感拉满
3. **最后 20%**（喘息）：障碍减少，小鱼增多，为玩家补血机会；终点码头在视野中出现

### 进度显示

HUD右侧显示一条**竖向进度条**，标注当前位置和终点距离，玩家随时知道快到了。

## 美术方向

-   **风格**：像素艺术（16×16 或 32×32 tile基准）
    
-   **调色盘**：每个场景一套主色调（草地：绿+棕，森林：橙+深绿，雪山：白+蓝灰）
    
-   **河水**：动态波纹像素动画，从上向下流动视觉效果，颜色随场景变化
    
-   **小船**：俯视视角，木质感，有小旗子
    
-   **UI**：像素字体，工具栏有木框质感
    

* * *

## 分数系统

-   存活时间 × 10 = 基础分
    
-   每收集一条鱼 +50分
    
-   无伤过关 +500分奖励
    
-   关卡结算界面显示本关 + 总分
